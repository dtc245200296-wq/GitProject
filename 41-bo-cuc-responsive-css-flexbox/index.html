Kỹ Thuật Xây Dựng Bố Cục Với CSS Flexbox

1. Nguyên Lý Tự Đoạn Co Giãn

Bằng cách sử dụng thuộc tính flex: 3; cho phần nội dung chính và flex: 1; cho thanh bên, bố cục tự động chia tỷ lệ 75% - 25% hoàn hảo trên giao diện máy tính.

2. Tương Thích Thiết Bị Di Động

Khi màn hình thu nhỏ hơn 768px, thuộc tính flex-direction: column; trong Media Query sẽ chuyển toàn bộ cấu trúc sang dạng xếp chồng chiều dọc.
